# Identify the editable source or format

For a finished video, select keyframes around the transition and test a proposed reconstruction on the current timeline. Record the observed appearance, tentative method and missing evidence separately.

For your own project, inspect the asset manifest, readable source, documented API or exported JSON. Check the asset and application version before interpreting fields and units. When a native save produces an opaque document, use the application's own reopen, edit and export controls. A copy of the editable project and a short documented export can establish whether that version preserves the effect. Record source identity, observed behavior, result and outstanding questions in the work record. Follow [native production](jianying-hybrid.md) for a native timeline.
